# CPU-only PyTorch overlay for the Docling PDF pipeline.
#
# Installs everything from requirements.txt, but resolves torch/torchvision
# from PyTorch's CPU-only wheel index. The CPU wheels carry a "+cpu" local
# version (e.g. 2.14.0+cpu), which pip ranks above the plain PyPI build, so
# the CUDA-bundled wheels and the nvidia-* dependency tree are skipped
# entirely (~200 MB instead of ~4 GB on Linux; macOS is CPU-only either way).
#
# Usage:
#   pip install -r requirements-cpu.txt          # fresh install
#   pip install -r requirements-cpu.txt --upgrade --force-reinstall torch torchvision
#                                               # switch an existing install
#
# Pair with PDF_DOCLING_ACCELERATOR_DEVICE=cpu (see docs/pdf-docling-pipeline.md).
# GPU users: install from requirements.txt / requirements.lock as usual.

--extra-index-url https://download.pytorch.org/whl/cpu
-r requirements.txt
